# Usage report

Generated by `code/evaluation/build_reports.py` from `runs/usage.json`, which `python3 code/main.py run` writes. It covers the final full-dataset run that produced `output.csv`.

## What the run uses a model for

Exactly one stage: a second opinion on whether each of the 518 requests authorises deletion (375 distinct texts, one call per text per model, temperature 0). The deciding classifier is the rule baseline. The model answers are compared with it and never change a row, so `output.csv` does not depend on any model. All other stages (identity, evidence indexing, state, policy, planning, verification) are deterministic code with no model call.

Calls in this run were served from the shipped cache in `code/llm_cache`. Token counts are the ones recorded when each call was first made against Amazon Bedrock, so a cold re-run reports the same totals with 0 live calls.
